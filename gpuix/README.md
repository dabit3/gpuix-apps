# gpuix demos

Twelve apps built with [GPUIX](https://github.com/remorses/gpuix) 0.11.0 (React on Zed's GPUI,
rendered by Metal). In terminal mode the same React tree is painted into the terminal over the
Kitty graphics protocol, so each app behaves like a TUI: launch it from the prompt, split the pane
around it, Ctrl-C back to the shell.

## Shell shortcuts

One-word launchers live in `~/.zshrc` (the "GPUIX demo apps" block). Each alias runs the app's own
executable entry script through its `#!/usr/bin/env bun` shebang, so arguments pass straight
through and relative paths resolve against whatever directory you're in. The same commands are
also `bun link`ed into `~/.bun/bin`, so they work outside zsh too.

```zsh
alias caustic="$GPUIX_DEMO_HOME/caustic/src/cli.ts"
alias convt="$GPUIX_DEMO_HOME/convt/src/cli.ts"
alias couch="$GPUIX_DEMO_HOME/couch/src/cli.ts"
alias devin-tui="$GPUIX_DEMO_HOME/devin-terminal/app.tsx"
alias krieg="$GPUIX_DEMO_HOME/krieg/src/cli.ts"
alias photocraft="$GPUIX_DEMO_HOME/photocraft/bin/photocraft.tsx"
alias sinkhole="$GPUIX_DEMO_HOME/sinkhole/src/cli.ts"
alias surf="$GPUIX_DEMO_HOME/surf/src/cli.ts"
alias tokscope="$GPUIX_DEMO_HOME/tokscope/bin/tokscope.ts"
alias tradeterm="$GPUIX_DEMO_HOME/tradeterm/bin/tradeterm.tsx"
alias wasteland="$GPUIX_DEMO_HOME/wasteland/bin/wasteland"
alias yard="$GPUIX_DEMO_HOME/yard/bin/yard.ts"
```

where `GPUIX_DEMO_HOME` is the absolute path of this `gpuix/` folder.

| Command | App | Try it |
| --- | --- | --- |
| `caustic` | Real-time water caustics | `caustic -s lagoon` · `caustic drop` in a second pane |
| `convt` | Local file converter GUI | `convt demo -w` (watches the folder for new files) |
| `couch` | 10-foot media center | `couch ~/Movies` · `couch remote` in a split |
| `devin-tui` | Devin web app as a TUI | `devin-tui --demo` (or live with API credentials) |
| `krieg` | Procedural FPS | `krieg` · `krieg map` in a split for the live map |
| `photocraft` | Photoshop-style image editor | `photocraft photocraft/samples/lake.jpg` |
| `sinkhole` | DNS ad/tracker blocker + dashboard | `sinkhole`, then `dig @127.0.0.1 -p 5300 doubleclick.net` |
| `surf` | Real web browser (headless Chrome) | `surf https://news.ycombinator.com` |
| `tokscope` | Token-efficiency audit for agent transcripts | `tokscope tokscope/sample/` |
| `tradeterm` | Crypto charting + backtesting | `tradeterm BTC-USD 1h` |
| `wasteland` | Post-apocalyptic RPG | `wasteland` · `wasteland log -f` in a split |
| `yard` | Miller-column file manager GUI | `yard` (current dir) · `yard ~/Downloads` |

To reload the shortcuts after editing `.zshrc`: `source ~/.zshrc` (or open a new shell).
To remove them: delete the block between the `GPUIX demo apps` markers in `~/.zshrc`.

## Requirements

- **macOS** (Metal) and [Bun](https://bun.sh).
- **Ghostty or kitty** to render in the terminal (Kitty graphics protocol). tmux and the
  VS Code/Zed terminals stay blank — every app also supports `-w`/`--window`/`--native`
  for a plain native window instead.
- **Google Chrome** — required by `surf` (driven over raw CDP; `--chrome <path>` or
  `$SURF_CHROME` to point at Chromium).
- **ffmpeg/ffprobe** — required by `couch` and `convt` (installed via Homebrew).
- **cwebp, pandoc, typst** — optional `convt` engines (WebP, document → PDF).
- **sips, textutil, afplay, dig** — ship with macOS.

## The apps

### `caustic` — water caustics

CPU wave simulation + photon-splatting caustics + a multi-threaded ray tracer drawn into a
GPUIX `<img>`. Drag the water to ripple it, push the beach ball, orbit, zoom, make it rain.
Every running `caustic` shares its ripples with the others unless `--solo`.

```sh
caustic -s sunset -r          # golden-hour scene with rain
caustic drop -n 5             # drop ripples into all running panes
caustic --help                # scenes, quality, sun/depth, themes, workers
```

### `convt` — file converter

Sniffs files by magic bytes, offers only sensible target formats, shows a live before/after
preview, and converts beside the originals with local engines — nothing is uploaded.

```sh
convt demo/                   # the generated fixture folder
convt file.png -t webp -q 80
convt demo -w -y              # watch the folder, convert everything on launch
```

Sample files were generated by `bun run fixtures` into `convt/demo/` and `convt/demo-more/`.

### `couch` — media center

Plex-style home shelves, poster grid, seasons/episodes, profiles with per-profile Continue
Watching, and an ffmpeg-decoded player pushed straight into a GPUIX `<img>`.

```sh
couch ~/Movies                # browse a library (default ~/Movies)
couch fetch                   # download ~1.9 GB of open/CC movies into ~/Movies/Couch
couch remote                  # on-screen D-pad for a running couch (run in a split)
couch --plex <url> --token t  # a real Plex Media Server instead of local files
```

State lives in `~/.config/couch/state.json`, artwork/thumb cache in `~/Library/Caches/couch`.
`couch fetch` was **not** run during setup (large download) — run it if you want a demo library.

### `devin-tui` — Devin in the terminal

The Devin web app rebuilt in React, talking to the real Devin API v3: sessions sorted by
activity, live status, real transcripts, a composer that starts real sessions, Computer
(attachments) and Session/PR panels, light/dark themes.

```sh
devin-tui                     # live mode with credentials, else scripted demo data
devin-tui --demo              # force demo data
devin-tui -s dynatrace        # open the first session matching a query
devin-tui -m fast -r acme/web "Fix the flaky checkout test"
```

Credentials: `DEVIN_API_KEY` + `DEVIN_ORG_ID`, the macOS Keychain, or
`~/.config/devin-tui/config.json` (`{"apiKey": "...", "orgId": "org-..."}`, chmod 600).
Don't pipe stdin into it — GPUIX treats a stdin pipe as the automation protocol.

### `krieg` — procedural FPS

A `.kkrieger`-style FPS where every texture, sprite, room, sound and the music track is
generated by code at startup — zero asset files. CPU raycaster, three weapons, 31 monsters,
a Doom-style status bar.

```sh
krieg                         # play: WASD, mouse-drag to look, click to fire
krieg map                     # live tactical map — run it in a split next to the game
krieg -s 42 -g                # deterministic seed, god mode
krieg size                    # packed-build size report (budget: 64 KB)
```

### `photocraft` — image editor

Layered raster editor: brushes, clone stamp, selections, transforms, adjustment layers,
filters, a menu bar and a Ctrl-K command palette. Saves projects as `.pcraft`, exports PNG.

```sh
photocraft photocraft/samples/lake.jpg
photocraft                    # blank 1600x1000 canvas
photocraft shot.png -o out.png -m 2048
```

### `sinkhole` — DNS ad blocker

UDP DNS server + live dashboard: 40-bit hashed blocklist with binary search and a bloom
filter, upstream forwarding with fallback, TTL cache, query ring, per-domain stats.
Serves `127.0.0.1:5300` by default (macOS holds 5353 for Bonjour; 53 needs sudo).

```sh
sinkhole                      # serve + draw the dashboard in this pane
dig @127.0.0.1 -p 5300 ads.yahoo.com    # blocked → 0.0.0.0
sinkhole bench -n 1000        # 1,000 mixed queries: ads sink, the rest resolve
sinkhole update               # refresh ~/.sinkhole/blocklist.bin
```

The blocklist was downloaded during setup (~71k domains → `~/.sinkhole/blocklist.bin`).
Rules and settings persist in `~/.sinkhole/config.json`. `--headless` runs without the UI.

### `surf` — terminal web browser

Headless Chrome over a raw CDP WebSocket (no puppeteer): real pages screencast into the
pane; tabs, omnibox, find bar and status line are GPUIX. The viewport reflows live when
you split or resize the pane.

```sh
surf https://news.ycombinator.com
surf open https://ghostty.org   # from a second pane, drives the running browser
surf eval "document.title" · surf shot page.png · surf tabs · surf ls
```

Keys use Ctrl (Ghostty owns Cmd): Ctrl-L omnibox, Ctrl-T/W tabs, Ctrl-F find, Alt-←/→
history. Ctrl-C closes Chrome and deletes the throwaway profile.

### `tokscope` — transcript token audit

Point it at Claude Code, Codex CLI or Devin CLI transcripts: where the money goes by prompt
segment, cache hits/breaks, the priciest tool results to carry, and a ranked list of fixes.
Writes the whole report as `AUDIT.md`.

```sh
tokscope                      # ~/.claude/projects if present, else bundled sample/
tokscope tokscope/sample/
tokscope --audit sample/      # headless: write AUDIT.md, no UI
bun run replay                # in the app dir: append a session line-by-line to ./live
```

### `tradeterm` — charting + backtesting

Candles, volume, indicators (EMA/SMA/Bollinger/VWAP/SuperTrend/Donchian + RSI/MACD/
Stochastic/ATR/OBV), drawings, a watchlist and a strategy backtester with equity curve.
Data comes from keyless Binance/Coinbase endpoints; `--offline` uses built-in samples.

```sh
tradeterm BTC-USD 1h          # 1m 5m 15m 1h 4h 1D 1W
tradeterm ETH-USD 4h -s rsi   # start with a strategy loaded
tradeterm --offline
```

State (indicators, drawings, watchlist) persists in `~/.tradeterm/state.json`; downloaded
bars are cached in `~/.tradeterm/cache/`. Not investment advice; independent of TradingView.

### `wasteland` — RPG

WASTELAND: NEW YORK — a Fallout-flavored isometric RPG with zero asset files: procedural
Manhattan district, dialogue trees with skill checks, factions, T.A.R.G.E.T. turn-based
combat, a green-phosphor WRIST-LINK and CRT scanlines.

```sh
wasteland                     # title screen + character creation
wasteland -c                  # continue from ~/.wasteland/save.json
wasteland log -f              # follow the game log live in a split
wasteland radio "msg"         # broadcast into a running game
```

### `yard` — file manager

yazi/ranger-style Miller columns: parent · current · preview, with photo thumbnails/EXIF,
syntax-highlighted code, Markdown, JSON summaries, git status badges, fuzzy jump, and
copy/cut/paste that works across Ghostty splits.

```sh
yard                          # current directory
yard ~/Downloads · yard -a    # dotfiles
yard yard/sample              # bundled sample tree (photos, code, data, dotfiles)
```

`hjkl`/arrows navigate, `enter` opens, `/` fuzzy-searches, `space` marks, `y x p` copy/cut/
paste, `d` trash, `.` toggles hidden files.

## How this was set up

```sh
cd gpuix/<app> && bun install --registry https://registry.npmjs.org
bun link    # puts the bin on PATH (~/.bun/bin)
```

- The `~/.npmrc` registry proxy (`pkg.cognition.build`) enforces a 7-day minimum package
  age. `@gpuix/*@0.11.0` was published 2026-10-20, so installs were run once against
  npmjs directly. After **2026-10-27** the default registry serves it and plain
  `bun install` works.
- `pandoc` and `typst` were installed via Homebrew for `convt`'s document engines
  (`ffmpeg`, `webp`, `sips`, `textutil` were already present).
- `sinkhole update` fetched the StevenBlack blocklist → `~/.sinkhole/blocklist.bin`.
- `bun run fixtures` generated `convt/demo/` and `convt/demo-more/`.
- Each app has its own README.md with full flags, key tables and architecture notes;
  `bun test` and `bun run typecheck` work in every folder.
